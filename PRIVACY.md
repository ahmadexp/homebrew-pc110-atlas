# PC110 Atlas desktop privacy

Effective September 14, 2026.

The portable desktop edition processes imported BIOS and disk images locally.
It does not upload imported media, collect analytics, show advertising, or
require an application account. Selected files are copied into the local app
data directory for emulation. The original files are not modified.

External project, archive, and support links open in an external application.
Those services have their own privacy policies. Downloading updates through
a package manager contacts that package service under its own policies.

Imported files remain until replaced or removed. Uninstalling normally
preserves app data. See the desktop documentation for storage paths.

The IRIX edition reads the media paths supplied on its command line. Changes
to guest disks remain in memory and are discarded when the app exits.

For support or privacy questions, use the
[public issue tracker](https://github.com/ahmadexp/homebrew-pc110-atlas/issues).
Do not include private media, credentials, or personal information in an issue.
